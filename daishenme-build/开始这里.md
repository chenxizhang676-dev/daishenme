# 怎么把这个文件夹变成 APK —— 两条路，挑一条

> 说明：帮你整理这个文件夹的 AI 助手运行在一台**不能上网**的机器上，
> 而编译安卓 app 必须从网上下载好几个 G 的工具，所以它没法当场给你 APK。
> 但它已经把工程**全部整理好、改对了文件名、配好了自动化**，
> 下面两条路随便走一条，都能拿到 `daishenme.apk`。

---

## 路 A：网页上点几下，云端帮你编译（最省事，电脑上啥都不用装）⭐推荐

适合你这种不想折腾的情况。全程在浏览器里完成，不用装安卓开发软件。

1. 去 https://github.com 注册一个免费账号（如果还没有）。
2. 登录后点右上角的 **+ → New repository**（新建仓库）。
   - 名字随便起，比如 `daishenme`。
   - 选 **Private**（私有）也行。点 **Create repository**。
3. 新仓库页面里点 **uploading an existing file**（上传已有文件）这行字。
4. 把**本文件夹里的所有东西**拖进去上传。
   - ⚠️ 重要：要把 `www` 文件夹、还有那个名字以点开头的 `.github` 文件夹**一起**拖进去。
   - 拖完点底部绿色的 **Commit changes**。
5. 上传完后，点仓库顶部的 **Actions** 标签。
   - 第一次会让你点一下 **I understand my workflows, enable them**（启用）。
   - 左边点 **Build APK**，右边点 **Run workflow → Run workflow**。
6. 等大约 **5–10 分钟**（页面上的圈圈转完变成绿色对勾就是好了）。
7. 点进那次运行，拉到页面**最底部**，有个 **daishenme-apk**，点它下载。
   - 下载下来是个 zip，解压出来就是 `daishenme.apk`。
8. 把这个 apk 传到安卓手机上点开安装（手机要允许"安装未知来源应用"）。
   - 第一次打开 app 会问"是否允许通知"，点**允许**。

> 以后改了 `www/index.html`，重新上传覆盖、再 Run 一次，就能出新包。

## 路 B：在你自己的电脑上编译（按原 README 的方式）

如果你愿意装一次安卓开发环境（约 30–60 分钟），或者交给一个会安卓的朋友 / 交给 Claude Code、Cursor 这类工具替你跑：

1. 装 **Android Studio**（https://developer.android.com/studio），
   安装时让它把 **Android SDK** 一起装上（它自带合适的 JDK）。
2. 打开终端，`cd` 进入**本文件夹**，依次运行：
   ```bash
   npm install            # 装 Capacitor 等依赖（已在 package.json 配好）
   npx cap add android    # 生成安卓工程
   node patch-manifest.mjs  # 自动加"精确定时通知"权限（不用手动改文件了）
   npx cap sync           # 把网页同步进安卓工程
   ```
3. 编译 debug 版 APK：
   ```bash
   cd android
   ./gradlew assembleDebug      # Windows 上用：  gradlew.bat assembleDebug
   ```
4. 出好的 APK 在：
   `android/app/build/outputs/apk/debug/app-debug.apk`
   把它复制到本文件夹、改名 `daishenme.apk` 即可：
   ```bash
   cd ..
   cp android/app/build/outputs/apk/debug/app-debug.apk daishenme.apk
   ```
5. 传到手机安装，首次进 app 点**允许通知**。

> 想用 Android Studio 图形界面出包也行：`npx cap open android` 打开后，
> 菜单 **Build → Build App Bundle(s)/APK(s) → Build APK(s)**。

## 我（AI）已经替你做好的事

- 把上传时被改名的 `capacitor_config.json` 改回正确的 **`capacitor.config.json`**（必须是点）。
- 把 `_gitignore` 改回 **`.gitignore`**。
- 在 `package.json` 里**写好了依赖**，所以一条 `npm install` 就能装全，不用分好几次装。
- 写了 `patch-manifest.mjs`，**自动**加那行 `SCHEDULE_EXACT_ALARM` 权限，你不用手动去翻 XML 改文件。
- 写了云端编译流程 `.github/workflows/build-apk.yml`，对应上面的"路 A"。

## 提醒没弹怎么办

- 首次进 app 一定要点**允许通知**（漏点了去手机：设置 → 应用 → 带什么 → 通知，打开）。
- 小米/华为/OPPO 等省电较狠：把本 app 的**电池优化关掉 / 允许后台运行 / 允许自启动**。
- 排的拍摄时间必须在**未来**，过去的时间不会再排提醒。

## 文件夹里有什么

```
daishenme-build/
├── www/index.html              ← 你的整个 app
├── capacitor.config.json       ← app 名称/标识/网页目录
├── package.json                ← 依赖已配好
├── patch-manifest.mjs          ← 自动加权限的小脚本
├── .gitignore
├── 开始这里.md                  ← 本文件
└── .github/workflows/build-apk.yml  ← 云端编译流程（路 A 用）
```
